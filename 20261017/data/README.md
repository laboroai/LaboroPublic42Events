# data

ここにある `.csv` は、`python register.py` ですべて登録される。QAを書き直したら、もう一度 `register.py` を実行する。

| ファイル | 中身 | 触るか |
| :-- | :-- | :-- |
| `shakaijin_qa.csv` | 運営が用意した、社会人向けのメリットのQA（42 Tokyoの公式サイトの情報から作成） | 触らない |
| `my_qa.csv` | あなたが書く42の魅力QA。`question,answer` の2列。全員共通の3問が最初から入っている | **ここに書く** |
| `secret_qa.csv` | 当日配る固有QA。S5で `ops/sample_secret_qa.csv` をここにコピーする | コピーするだけ |

`my_qa.csv` には、全員共通の3問が入っている。まずこの3問の `,` のあとに、自分の答えを書く。そのあとに自由な質問と答えを足して、合わせて5〜10問にする。答えが空の行は登録されない。

自由に足すQAの例:

```csv
question,answer
42の一番の魅力は？,自分で調べて、仲間と教え合いながら課題を解き切る経験ができること。答えを教えてもらえないぶん、自分で考える力がつく。
```

答えの中にカンマを入れるときは、答え全体を `"` で囲む。個人情報や、ほかの人の名前は書かない（QAは外部のAIサービスに送られる）。
